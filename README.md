## 项目介绍

本项目是一个基于微信云开发（CloudBase）的智能废品回收微信小程序，面向居民线上预约废品上门回收、分享回收心得的场景，无需自建服务器，小程序前端直接调用云数据库与云存储，打通「发布回收预约—积分奖励—回收心得社区」的业务闭环，可作为微信小程序云开发的学习案例。

### 系统角色
- **普通用户（居民）**：微信登录小程序后发布废品回收预约、浏览回收站点与回收心得、对心得评论点赞收藏、维护个人资料与积分。
- **权限控制**：纯云开发架构，无独立管理端；用户身份由 `cloudfunctions/login` 云函数换取微信身份后写入 `Users` 集合，数据读写由小程序前端直连云数据库，云函数侧自带微信私有协议鉴权。

### 小程序功能
1. **首页**：展示系统介绍入口与最新内容。
2. **发布回收**：选择回收站点与交付时间，填写废品名称、类型、数量、备注并上传废品照片，提交成功奖励 5 积分。
3. **我的发布**：查看本人提交的回收预约记录，支持删除。
4. **心得社区**：按分类浏览用户分享的回收心得帖子，进入详情后可评论、点赞、收藏。
5. **分享心得**：发表图文回收心得帖子，并在「我的心得」中管理自己发布的帖子。
6. **个人中心**：维护个人资料、查看积分、查看系统介绍与关于信息。

### 技术栈
- **前端**：微信原生小程序（`miniprogram/`），原生 WXML/WXSS/JS，无第三方框架。
- **云开发**：微信云开发 CloudBase，云环境 ID `cloud1-0g4ju7fj0c10d396`；1 个云函数 `login`（微信登录）。
- **数据与存储**：云数据库 JSON 文档集合 + 云存储（`wx.cloud.uploadFile` 上传废品照片）。

### 云数据库集合
- `Users` 用户集合：微信用户信息、积分 `jifen`。
- `Result` 回收预约集合：物品名称 `name`、废品类型 `type`、数量 `num`、备注 `mess`、回收站点 `dateweek`、交付时间 `time`、照片 `img`、发布时间 `sendDate`、用户信息 `userInfo`。
- `Work` 回收站点集合：站点名称 `name`。
- `Chang` 回收心得帖子集合：帖子图文内容与发布人。
- `CommentList` 心得评论集合：帖子评论内容。
- `DzMess` 点赞记录集合、`ScMess` 收藏记录集合。

# 云开发 quickstart

这是云开发的快速启动指引，其中演示了如何上手使用云开发的三大基础能力：

- 数据库：一个既可在小程序前端操作，也能在云函数中读写的 JSON 文档型数据库
- 文件存储：在小程序前端直接上传/下载云端文件，在云开发控制台可视化管理
- 云函数：在云端运行的代码，微信私有协议天然鉴权，开发者只需编写业务逻辑代码
